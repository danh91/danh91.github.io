Now

Product engineer at JTL-Software, leading Karrio inside it.

I founded Karrio in 2020 on one idea: carrier integration is infrastructure, and infrastructure should be open. In 2025 Karrio and I joined JTL-Software, where it runs as the shipping layer inside an established European e-commerce software business.

Before that I was founding engineer and then CTO at Teleship, building cross-border shipping architecture, and a decade of production systems before that.

What I care about now: logistics is about to be run by software rather than by people clicking through dashboards. Carrier selection, rate negotiation, exception handling, customs decisions. All of it becomes something a machine can address directly. Most of this industry is still shipping dashboards.

The main thing

Karrio

Open-source shipping platform, API-first, self-hostable

Rating, label generation, tracking, customs documentation and fulfillment orchestration behind one interface. A plugin SDK lets a team add a carrier without waiting on somebody's roadmap. UPS, DHL, FedEx, USPS, Canada Post, Purolator and a growing ecosystem beyond them.

Started as a side project in 2020. Became production infrastructure for platforms, retailers and logistics teams, with a contributor community extending it into markets I will never see.
