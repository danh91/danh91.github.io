# danh91.github.io
Personal site, dankobina.com

Plain HTML with a shared stylesheet in `assets/site.css`. There is no build step or client-side JavaScript.

- `/`: About
- `/writing/`: Writing
- `/work/`: Selected work
- `/work/karrio/`: The Karrio project account

GitHub Pages publishes the root of `main` to [dankobina.com](https://dankobina.com/). `CNAME` preserves the custom domain. Keep `sitemap.xml` in sync when adding pages.

Preview locally with `python3 -m http.server 8000`, then open `http://localhost:8000/`.
